O dashboard não apareceu?

No Grafana, habilite allow_embedding = true na seção [security] e reinicie o serviço. Use o mesmo nome de endereço no portal e no Grafana (por exemplo, localhost nos dois). Se aparecer login, use “Voltar” e o link “Ir para o Grafana” do card para entrar com sua conta. Depois abra o dashboard aqui novamente.
